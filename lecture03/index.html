物理设定

把一个电子关进一维盒子

模型

一个电子被限制在宽度 $L$ 的一维区间内。盒子内部势能为零（电子自由），盒壁势能无穷高（电子绝对出不去）。

边界条件从哪来？

波函数 $\psi(x)$ 必须处处连续。盒壁外势能无穷大 → 电子不可能出现在那里 → 那里 $\psi=0$。

连续性要求盒内的 $\psi$ 在边界处与盒外接上，于是：

$\psi(0)=0,\qquad \psi(L)=0$

这两个看似不起眼的条件，正是后面所有量子化结果的源头。

为什么这个模型重要

它简单到能用手算出全部解，却已经包含量子力学最核心的三个特征：能量量子化、零点能、波函数节点。是理解一切更复杂体系的「第一块拼图」。

解方程 · 主线

从薛定谔方程到一串离散能级

盒内：方程变成「驻波方程」

盒内 $V=0$，定态薛定谔方程只剩动能项：

$-\dfrac{\hbar^2}{2m}\,\psi'' = E\,\psi \;\;\Rightarrow\;\; \psi'' = -k^2\psi$

其中 $k^2 = 2mE/\hbar^2$。这正是描述驻波的方程，通解是正弦与余弦。

边界条件「挑出」离散的 k

$\psi(0)=0$ 去掉余弦项；$\psi(L)=0$ 要求 $\sin(kL)=0$，于是 $k$ 只能取：

$k_n = \dfrac{n\pi}{L},\qquad n=1,2,3,\dots$

连续的 $k$ 被边界条件筛成了一串离散值 —— 量子化在这里发生。

结论：能级与本征态

$E_n = \dfrac{n^2 h^2}{8mL^2} = \dfrac{n^2\pi^2\hbar^2}{2mL^2}$
$\psi_n(x) = \sqrt{\dfrac{2}{L}}\,\sin\!\dfrac{n\pi x}{L}$

能量只能取 $n^2$ 倍的离散值；$n$ 称为量子数。

展开完整推导（主线读者可跳过）
  1. 盒内 $V=0$，定态方程：$-\dfrac{\hbar^2}{2m}\psi'' = E\psi$
  2. 整理为 $\psi'' = -k^2\psi$，其中 $k^2 = 2mE/\hbar^2$ —— 驻波方程
  3. 通解：$\psi(x) = A\sin(kx) + B\cos(kx)$
  4. 套 $\psi(0)=0$：因 $\cos 0 = 1$，必须 $B=0$，故 $\psi = A\sin(kx)$
  5. 套 $\psi(L)=0$：要求 $\sin(kL)=0$，即 $kL = n\pi$，得 $k_n = n\pi/L$
  6. 代回能量：$E_n = \dfrac{\hbar^2 k_n^2}{2m} = \dfrac{n^2\pi^2\hbar^2}{2mL^2} = \dfrac{n^2h^2}{8mL^2}$
  7. 归一化：$\displaystyle\int_0^L |A|^2\sin^2\!\dfrac{n\pi x}{L}\,dx = |A|^2\dfrac{L}{2} = 1 \;\Rightarrow\; A=\sqrt{2/L}$

注：$n=0$ 给出 $\psi\equiv0$（无粒子，无意义），负 $n$ 不产生新态 —— 所以 $n$ 从 1 开始。

第 $n$ 个本征态 $\psi_n$ 有 $n-1$ 个节点。节点越多 → 波函数弯曲越剧烈 → 动能越大 → 能量越高（$E_n\propto n^2$）。左图是 $\psi_n$（可正可负），右图是 $|\psi_n|^2$（处处非负，才是「在某处找到电子」的概率密度）。

三个关键物理特征

这个简单模型告诉我们什么

特征一 · 能量量子化

能量只能取离散值

能量不连续，不是人为假设，而是「波函数必须在边界为零」这个条件的数学后果 —— 只有特定波长的驻波能塞进盒子。

就像两端固定的吉他弦只能发出特定的几个音。

特征二 · 零点能

$E_1 \neq 0$，电子停不下来

最低能量 $E_1 = h^2/8mL^2 > 0$。电子不可能完全静止地待在盒底。

这与不确定性原理一致：把电子限制在宽度 $L$ 内（$\Delta x\sim L$），动量就必然有涨落（$\Delta p\gtrsim\hbar/L$），于是动能 $\sim(\Delta p)^2/2m>0$。

特征三 · 节点

波函数形状与节点数

$\psi_n$ 有 $n-1$ 个节点（波函数为零的内部点）。

节点数越多，波函数在盒内弯曲得越厉害，曲率越大 → 动能越大。这就是「节点越多、能量越高」的物理来源。

数值感

代入真实数字：能级落在什么能量范围？

算一个典型尺度

取电子质量 $m=9.11\times10^{-31}$ kg，盒宽 $L=5\,\text{Å}=5\times10^{-10}$ m。代入 $E_n=n^2h^2/8mL^2$：

量子数 n能量 $E_n$相对 $E_1$
1≈ 1.5 eV1×
2≈ 6.0 eV4×
3≈ 13.5 eV9×

最低跃迁 $E_2-E_1\approx 4.5$ eV。用 $\lambda(\text{nm})\approx 1240/E(\text{eV})$ 换算 → ≈ 275 nm。

这个数字意味着什么

4.5 eV / 275 nm 落在紫外波段（可见光约 1.6–3.1 eV）。

一个 5 Å 的小盒子，能级间距太大，吸收在紫外 —— 肉眼看不到颜色。

关键直觉

因为 $E_n\propto 1/L^2$：要把吸收红移进可见区，就需要更大的 L —— 也就是更长的盒子。这正是下一屏「共轭链」的钥匙。

量纲速记

$\lambda(\text{nm}) \approx 1240 / E(\text{eV})$ —— 光子能量与波长的换算，做光谱估算时极常用。

落到有机电子学

为什么共轭链越长，吸收越红？

π 电子 ≈ 盒中粒子

共轭分子里离域的 $\pi$ 电子，可近似看作被关在一维「盒子」里的粒子。盒子的有效长度就是共轭链长：

$L \approx (N_C+1)\,d,\quad d\approx 1.4\,\text{Å}$

$N_C$ 为共轭碳原子数，$d$ 为平均 C–C 键长。

推理链

链越长 → $L$ 越大 → $E_n\propto 1/L^2$，HOMO–LUMO 间隙 $\Delta E$ 越小 → 吸收光子能量越低 → 波长 $\lambda\propto L^2$ 越长 → 吸收红移。

实验检验：聚并苯系列

分子苯环数吸收峰颜色
萘2~220 nm无色
蒽3~380 nm无色
并四苯4~480 nm橙色
并五苯5~580 nm蓝紫色

环越多、链越长，吸收峰单调红移 —— 与 $\lambda\propto L^2$ 的趋势完全吻合。

模型的边界

自由电子模型定性正确、定量粗糙。偏差来自电子–电子排斥、键长交替、端点效应。更精确的处理是 Hückel 理论（第九讲）。

小结

无限深方势阱 · 速查卡

核心公式

$E_n = \dfrac{n^2h^2}{8mL^2} = \dfrac{n^2\pi^2\hbar^2}{2mL^2}$
$\psi_n(x) = \sqrt{\dfrac{2}{L}}\,\sin\dfrac{n\pi x}{L}$
  • 节点规则：$\psi_n$ 有 $n-1$ 个节点
  • 零点能：$E_1 = h^2/8mL^2 \neq 0$
  • 尺寸定律：$E_n\propto 1/L^2$，$\;\lambda\propto L^2$
  • 能量换算：$\lambda(\text{nm})\approx 1240/E(\text{eV})$
一句话总结

「波函数必须在盒壁为零」这一个边界条件，就同时逼出了能量量子化、零点能和波函数节点 —— 量子力学的三个核心特征。

为什么对有机电子学重要

$E_n\propto 1/L^2$ 把「共轭链长度」和「带隙 / 吸收颜色」定量地连了起来 —— 这是理解有机半导体光学性质的第一块基石。
